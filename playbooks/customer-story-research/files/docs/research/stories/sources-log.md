What each platform yielded in past story-research runs and what blocked agents there, so every
run starts from what worked. After each run the lead adds a row for each new platform and updates
the rest. Say what a venue gives the next run: "Shows App Store reviews in full text where the App
Store page doesn't" helps the next planner; "All retained quotes rechecked" doesn't. Platforms are
sites, not people: group personal blogs and newsletters into one "Personal blogs" row, so the log
stays readable. Write yield and access only, never fit scores or who the stories suited: the next
run's planning agent reads this file blind.
