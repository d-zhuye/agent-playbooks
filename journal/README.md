# Journal

Short entries on problems that keep coming back, and what was tried, before they are proven
enough to become playbooks. The template and rules are in [CONTRIBUTING.md](../CONTRIBUTING.md).
Reviews promote, merge or delete entries (see [REVIEWING.md](../REVIEWING.md)).

## Topics

- [App Store release stakeholder decisions](app-store-release-stakeholder-decisions.md): questions about stakeholder interests, user alternatives and evidence to guide metadata, screenshots and release information; untested.
- [Generate character animations](generate-character-animations/README.md): how to make, repair and speed up vector character animations from reference art, condensed on one page, with the full history and performance evidence behind it.
- [Character animations on Skia](character-animations-skia/README.md): moving a generated vector character from one native view per part to a single Skia canvas, the traps on the way, and the soft shadows, clips and motion smears the canvas then allows.
